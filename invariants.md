# Инвариант 1: Закон Атомарной Цепочки Ответственности

У любого оборудования в любой момент времени может быть только один активный «хозяи (ответственный) или одно «место» (склад/студия). Переход ответственности атомарен.

# Инвариант 2: Закон Примата Физики через Дополнение, а не Стирание

Цифровая запись никогда не удаляется и не перезаписывается «задним числом» для соответствия физике. Физическая реальность побеждает цифру путем создания нового события-коррекции.

# Инвариант 3: Закон Привязки Состояния к Событию

Изменение физического состояния объекта (Работает -> Сломан) не может существовать в вакууме. Оно всегда является следствием или частью события передачи ответственности или аудита.

# Инвариант 4: Закон Уникальной Идентичности

Item_ID является первичным ключом реальности для индивидуально учитываемых объектов. Количественно учитываемые объекты не являются Item и учитываются через SKU / StockLot / Balance с неизменяемым журналом движений.
